## Taller 7

###¿Qué encontrarás en este repositorio?

El desarrollo de Taller 7 de Ing Web de la PUCV, 2do semestre 2026

Desarrollado en Ionic + React, la página incluye;

- Peticiones en backend y frontend
- GET, POST, DELETE implementados
- DELETE de una publicación con id 1 funcionando

Para correr el servidor backend, utilizar:
```
npm run dev
```
Para frontend:
```
ionic serve
```
En sus respectivas carpetas utilizando cd/ donde corresponda.
